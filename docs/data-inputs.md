# Data Inputs

This pack works best when inputs are supplied at runtime. Do not infer market facts from memory.

## Shared Context Inputs

- `[TARGET_MARKET]`
- `[TARGET_LANGUAGE]`
- `[TARGET_CHANNEL]`
- `[BRAND_TONE]`
- `[REGULATORY_NOTES]`
- `[T&CS]`
- Campaign objective
- Budget or bonus-cost limit
- Launch timing and expiry timing
- Eligible products and eligible markets
- Exclusion rules

## Customer Inputs

- Customer ID or anonymised row key
- Lifecycle stage
- Registration date
- First deposit status
- Deposit frequency and value bands
- Stake level
- Active days
- Recency of last sportsbook activity
- Sport preference
- Event affinity
- Bet type preference
- Pre-match versus live betting tendency
- Single versus accumulator tendency
- Bet builder usage
- Odds boost usage
- Free bet usage
- Cashback usage
- Bonus history
- Bonus sensitivity
- VIP status
- Churn risk score
- Sharp or arb sensitivity flag
- Bonus abuse risk flag
- RG risk flag
- Self-exclusion status
- Marketing consent
- Channel eligibility
- Frequency-cap status

## Campaign Inputs

- `[TARGET_SEGMENT]`
- `[TARGET_EVENT]`
- `[TARGET_SPORT]`
- `[OFFER_MECHANIC]`
- `[OFFER_VALUE]`
- Minimum odds
- Minimum stake
- Maximum bonus value
- Eligible bet types
- Eligible markets
- Expiry
- CTA destination
- Control group size
- Measurement window
